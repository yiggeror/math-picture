## 傅里叶旋转圆绘画 (`index.html`)

用浏览器直接打开 `index.html`。把一条闭合曲线采样成复数点列，做离散傅里叶变换，
每一项是一个按自身频率旋转的圆，首尾相接，末端的笔尖就会画出原图。

- 图案：猫、心形、五角星、任意文字、手绘一笔
- 「逐级增加圆」：1、2、4、8…个圆依次绘制，看图案从模糊的椭圆变成清晰的轮廓

## 星月夜 · 傅里叶竖屏视频 (`video/`)

一个圆带着一个圆旋转，末端的笔尖画出梵高《星月夜》。1080×1920、60 fps、44 秒，配乐同步。

- 每一轮圆的数量翻倍：1、2、4……16384，每一轮笔尖把整幅画完整画一遍；
- 圆少的时候只画得出光滑的大曲线，圆越多细节越清楚：低频画轮廓、高频补细节，这就是傅里叶级数；
- 前几轮的线条换个颜色留在后面慢慢变淡，镜头随曲线变大往后拉，越往后每轮越短；
- 最后一轮镜头扎到笔尖上看几千个小圆转动，再拉回全景，最后一笔闭合时圆炸开，所有轮次的彩色曲线一起闪现，然后收拢成原画颜色的成品。

```bash
pip install numpy scipy pillow       # 一次即可
cd video
python3 make_path.py    # 原画 → 笔触流线 → 一笔画 → FFT → 每一轮的曲线，输出 data/
python3 music.py        # 合成配乐 music.wav
node render.js          # 逐帧渲染并混入音乐 → starry_night.mp4
node render.js --stills 600,1800     # 只导出几帧 PNG 预览
node render.js --mux                 # 改了配乐后只重新合成音轨
```

- `make_path.py`：按原画笔触方向场追踪 665 条长流线，从中央大漩涡开始按“最近的线头”串成一条闭合曲线，等弧长采样 32768 点做 FFT，圆按半径从大到小排序；每一轮的曲线是前 N 个圆画出来的结果（逆 FFT）。
- `scene.html`：Canvas 渲染器，镜头、配色、圆的绘制、高潮效果都在这里。
- `music.py`：用 numpy 合成的原创配乐，每一轮开头一个音，随圆的数量翻倍升高，时间点读 `config.json`。
- `config.json`：每一轮的圆数和时长、揭晓后的时长、节拍。
- 原画《星月夜》为公有领域作品（图片来自 Wikimedia Commons）。
